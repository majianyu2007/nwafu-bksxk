## 本次更新：v2.1.1 修复统一身份认证二次验证「应用未注册」问题

本次热修版本修复了 v2.1.0 在进入统一身份认证二次验证（MFA）并输入验证码提交登录时提示「应用未注册」的问题，并同步加固了二次验证解析与错误提示。

### 统一身份认证与二次验证
- **修复二次验证提交提示「应用未注册」**：学校 AuthServer 的 `reAuthLoginView.do` 通过 Thymeleaf 内联 JS 输出 `reAuthParams` 时，会将 `service` 地址中的 `/` 转义为 `\/`（及 `&` 转义为 `\u0026` 等）。新增专用 JS 对象与字符串反转义解析器，限定从 `reAuthParams` 中解析并还原干净的 `service` URL，避免将带 `\/` 的地址提交给 `reAuthSubmit.do` 与后续登录跳转。
- **完善 `service` 安全校验与回退链**：对页面提取的 `service` 做单层重复 URL 编码纠偏及校内域名白名单校验，异常或缺失时依次回退到 `reAuthLoginView.do` 跳转参数和原登录目标地址。
- **优化错误分类与提示**：区分二次验证会话过期（302 重定向）、非 JSON 异常响应及服务端「应用未注册 / 无权访问」（`no-access-or-registered-tip`），不再误报为验证码错误；二次验证选择「认证密码」时保留密码首尾空白字符。

## 下载与使用

下载下方对应平台的安装包。
- 网页版：https://mjy.js.org/nwafu-bksxk/app/
- 桥接脚本（推荐 1.5.1）：https://mjy.js.org/nwafu-bksxk/bksxk-web-bridge.user.js

各平台说明：
- **Android**：常规手机选 `arm64-v8a`，较老的 32 位设备选 `armeabi-v7a`；`AAB` 供商店分发使用，不能直接安装。
- **Windows**：`x64` 或 `ARM64` 的 ZIP，解压后运行。
- **macOS**：Universal DMG（支持 Apple Silicon 与 Intel，需要 macOS 14 及以上），未经过公证，首次打开需在系统设置 → 隐私与安全性中允许。
- **Linux**：`x64` 或 `ARM64` 的 `tar.gz`，需要 GTK、libsecret 和 Ayatana AppIndicator。
- **iOS**：未签名 IPA，需自行签名安装。

检查更新会访问 GitHub 和 `mjy.js.org`，不会发送学校账号、密码或 Cookie。
