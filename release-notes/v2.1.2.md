## 本次更新：v2.1.2 修复全平台图书馆登录态失效与 Cookie 持久化覆写问题

本次热修版本彻底修复了打开「图书馆」页面立即提示「统一身份认证未登录或已过期」、重新登录后仍然报错的问题（在 iOS/Android/macOS/Windows/Linux 原生端均可能触发），并同步加固了教务、门户与图书馆的二次验证处理。

### Cookie 管理与图书馆认证修复
- **修复跨域名 `302` 重定向覆写统一身份认证凭证的根因**：
  - 移除会跨域名复制 `3xx` `Set-Cookie` 的上游 `dio_cookie_manager`，新增严格遵循 RFC 6265 的 `OriginScopedCookieManager`，仅将每个响应的 `Set-Cookie` 写入其自身源站，避免图书馆 `booking-lib.nwafu.edu.cn/api/cas/cas` 302 返回的 `PHPSESSID` 写入 `authserver.nwafu.edu.cn`，同时杜绝 `CASTGC` 泄漏到业务域名。
  - 新增 `SafePersistCookieJar` 替代 `PersistCookieJar`，串行化读写并在 `saveFromResponse` 前先加载该主机已持久化的 Cookie，避免冷启动时首次写入直接覆盖清空 Keychain/Keystore 中的 `CASTGC` 与 `MULTIFACTOR_BROWSER_FINGERPRINT`。
- **修复二次验证误清空会话循环**：
  - 图书馆、教务与学校门户在跳转至 `/authserver/reAuthCheck/` 二次验证页时，不再触发无法完成二次验证的静默重登（此前会清空当前有效 `CASTGC`），改为明确提示需要二次验证并引导勾选「信任此设备」。
  - 移动端（iOS / Android）二次验证默认勾选「信任此设备」（桌面端与网页版保持默认不勾选）。
  - 修正统一身份认证登录页错误提示正则 `formErrorTip` 跨出 `</div>` 误匹配「7天免登录」的问题。
- **修复图书馆状态复用与重新登录刷新**：
  - 将 `LibraryService` 生命周期纳入 `EduClient` 统一管理并在重新登录后自动重置 token；图书馆错误页与入馆码弹窗点击「重新登录」成功后自动刷新全部图书馆视图。

## 下载与使用

下载下方对应平台的安装包。
- 网页版：https://mjy.js.org/nwafu-bksxk/app/
- 桥接脚本（推荐 1.5.1）：https://mjy.js.org/nwafu-bksxk/bksxk-web-bridge.user.js

各平台说明：
- **Android**：常规手机选 `arm64-v8a`，较老的 32 位设备选 `armeabi-v7a`；`AAB` 供商店分发使用，不能直接安装。
- **Windows**：`x64` 或 `ARM64` 的 ZIP，解压后运行。
- **macOS**：Universal DMG（支持 Apple Silicon 与 Intel，需要 macOS 14 及以上），未经过公证，首次打开需在系统设置 → 隐私与安全性中允许。
- **Linux**：`x64` 或 `ARM64` 的 `tar.gz`，需要 GTK、libsecret 和 Ayatana AppIndicator。
- **iOS**：未签名 IPA，需自行签名安装。

检查更新会访问 GitHub 和 `mjy.js.org`，不会发送学校账号、密码或 Cookie。
