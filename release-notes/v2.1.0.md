## 本次更新：v2.1.0 全面重构、网页版体验升级与问题修复

本版本围绕全仓代码审查与深度优化展开，修复了选课、监控、统一认证、图书馆、课表同步与通知等环节的多个边界 Bug，重构并拆分了多个超大模块，同时显著改进了网页版和选课界面的使用体验。

### 选课与监控
- **统一选课 UI 风格与课表预览**：优化选课主页、课程浏览、轮次切换与选课预览课表界面，整体视觉与液态玻璃主题统一，并增强不同屏幕尺寸下的排版适配。
- **修复首次登录选课轮次异常问题**：在选课系统登录及网页版桥接中隔离旧会话并刷新集群节点路由（`X-Bksxk-Refresh-Route`），彻底解决首次登录出现过期轮次的异常现象。
- **监控与抢课引擎加固**：修复频率限制 / 会话过期 / 队列确认拒绝时可能导致的监听卡在 `grabbing` 状态问题；将全校课程扁平列表归并优化为 O(N)，大幅减少搜索与过滤时的重建开销。
- **验证码识别体验优化**：拉取到验证码图片后立即展示并允许随时手动输入，后台 OCR 不再阻塞输入或覆盖已手动填写的内容。

### 网页版与桥接脚本 v1.5.1
- **应用内统一身份认证登录**：网页版退出登录后无需跳转到学校官网，直接在应用内即可完成账号密码登录、MFA 二次验证与静默重登。
- **桥接脚本升级至 1.5.1**：完善 `dqzc.do` 当前教学周放行、`ensureFreshBksxkRoute` 路由刷新竞态处理、多值响应头解析与 XHR 生命周期事件兼容性。
- 网页版与桌面/移动端均可直接清除课程缓存，状态提示中可一键跳转更新桥接脚本。

### 图书馆与校园服务
- **研讨室与座位预约优化**：支持研讨室实景图、当日时间轴冲突提示与自动 4 小时智能时段选取；修复极端开放时段下 `.clamp` 边界异常、日期切换旧数据残留以及平面图 `ui.Image` 显存泄漏，并引入有界 LRU 图片缓存。
- **学业进度、成绩与空教室**：独立拆分 GPA 模拟器与目标反推面板（适配键盘弹起与隐私隐藏）；空教室查询索引缓存化，修复窄屏与大字号下的布局溢出；修复一网通办 HTML 实体二次解码问题。

### 后台同步、日历与架构清理
- **日历与通知修复**：修复系统日历写入时区标注与清理残留、iOS 64 条本地通知上限裁剪、晚间单起点考试时间解析，以及后台刷新尊重「后台使用本设备通行密钥」开关。
- **安全与健壮性**：个人中心密码复核在缺少加密 Cookie 时强制拒绝明文发送；自定义选课服务器地址保存后实时同步到校园网代理；全面补齐异步回调的 `mounted` / 取消保护。
- **代码架构重构**：清理冗余实现与死代码，将 `library_page.dart`、`settings_page.dart`、`grades_page.dart` 拆分为职责清晰的子模块，细化 Riverpod `.select()` 监听粒度以减少无效重绘。

## 下载与使用

下载下方对应平台的安装包。
- 网页版：https://mjy.js.org/nwafu-bksxk/app/
- 桥接脚本（推荐 1.5.1）：https://mjy.js.org/nwafu-bksxk/bksxk-web-bridge.user.js

各平台说明：
- **Android**：常规手机选 `arm64-v8a`，较老的 32 位设备选 `armeabi-v7a`；`AAB` 供商店分发使用，不能直接安装。
- **Windows**：`x64` 或 `ARM64` 的 ZIP，解压后运行。
- **macOS**：Universal DMG（支持 Apple Silicon 与 Intel，需要 macOS 14 及以上），未经过公证，首次打开需在系统设置 → 隐私与安全性中允许。
- **Linux**：`x64` 或 `ARM64` 的 `tar.gz`，需要 GTK、libsecret 和 Ayatana AppIndicator。
- **iOS**：未签名 IPA，需自行签名安装。

检查更新会访问 GitHub 和 `mjy.js.org`，不会发送学校账号、密码或 Cookie。
