## 本次更新（v2.1.0 验收草稿）

### 校园生活全覆盖（原生闭环，超越官网体验）
- **图书馆全原生体验**：
  - **可视化楼层平面图选座**：加载楼层参考图与实时座位坐标，支持 1×–5× 缩放平移、状态图例、点选空座一键预约，也可随时切换列表搜索模式。
  - **研讨室全原生预约**：支持选日期与时段、填主题/内容/电话、按学号实时查询添加参与成员并 AES 加密提交，无需跳转网页。
  - **高频效率增强**：支持星标置顶常用自习区/研讨室、按校区筛选、在「我的预约」原生签到/暂离/续座/签退/取消以及随时出示入馆二维码。
- **成绩与 GPA 模拟器**：新增原生「GPA 模拟器」（支持添加假设课程或勾选排除已有课程，实时对比均绩与加权变化），并新增课程搜索、必修/选修筛选与按学期/绩点/学分排序。
- **学业进度**：接入教务学业完成情况（`xywccx`），采用柔和主题色进度条与宽屏双列课组卡片。
- **消息与待办**：接入一网通办消息、待办事项与学校新闻通知，宽屏双栏排布。
- **「我的」页与今日一览**：新增基于本地缓存的「今日一览」动态卡片（正在上的课/下节课倒计时与教室/GPA 快览），整合校园工具与统一身份认证一键自动登录选课。

### 统一身份认证（同步 `nwafu-cas` 1.0.1）
- 同步最新 CAS 登录协议：动态读取登录表单字段、支持 `checkNeedCaptcha.htl` 验证码预检、FIDO2 通行密钥携带 `sessionToken`、二次认证前自动注册浏览器指纹（`/bfp/info`）以稳定「信任此设备」。
- 二次认证补全全部验证码渠道（短信、企业微信、今日校园、邮箱、钉钉、WeLink、公众号）、6 位安全令牌 OTP 以及认证密码。

### 全端自适应、液态玻璃与轻量化
- **智能缩放与自适应布局**：设置 → 外观新增「界面缩放」（自动 / 紧凑 / 标准 / 宽松）；小屏手机、横屏手机自动切换紧凑侧边栏/胶囊栏防溢出，平板与桌面端「我的」页自动双栏排布。
- **液态玻璃 Chrome**：导航胶囊、侧边栏与悬浮层接入 `fluid_glass` `LiquidPanel`（仅作用于 Chrome 层，列表卡片保持零模糊开销；保留「玻璃效果」开关兼顾省电）。
- **低资源占用与桌面体验**：主标签页改为按需懒加载，降低冷启动内存与订阅开销；桌面端支持最小窗口约束、窗口尺寸记忆与快捷键（`Cmd/Ctrl+1~5` 切页、`Cmd/Ctrl+=/-/0` 缩放）。
- **三尺寸桌面小组件与提醒增强**：Android/iOS 支持 1×1 / 2×1 / 2×2 课表小组件及后台同步刷新；课前提醒支持首节课提前、同教室跳过、换楼提醒。

### 网页版
- 桥接脚本升级至 `1.4.0`，扩展覆盖 `newehall.nwafu.edu.cn` 与 `booking-lib.nwafu.edu.cn`，网页版同步开放「消息」与「图书馆」。
- 修复 `main.dart` 的 `dart:io` 条件导入隔离，确保 Web Release 构建干净通过。
