西农教务助手

课表、成绩、考试、空教室和选课，放在一个应用里

给西北农林科技大学学生用的开源客户端。用学校统一身份认证登录一次，日常查课表、成绩、考试和空教室；选课季也能用它选课、抢课。

下载客户端 网页版 源代码
学校接口只对校园网开放。客户端在校外可以用内置的校外访问，网页版需要在校园网内使用。

功能

课表数据同步后存在本机，没有网络时也能看。

课表

  • 按周显示，自动标出当前教学周，冬令、夏令作息时间分开算
  • 定时同步，调课、换教室时发通知
  • 上课前提醒，可以同步到系统日历或导出 .ics
  • Android 桌面小组件显示下一节课

成绩和考试

  • 按学期查看成绩、学分和绩点变化
  • 考试安排：时间、地点、座位号

空教室

  • 按日期、节次和教学楼查询空闲教室
  • 根据当天课表，推荐两节课之间可以去自习的教室

账号和登录

  • 使用学校统一身份认证，支持二次验证
  • 可以给本机绑定一个通行密钥，之后用指纹或面容解锁登录
  • 密码存在系统安全存储里，不上传到别处

校外访问

  • 客户端内置校园网接入，在校外也能同步课表、查成绩
  • 只有访问学校网站的请求会经过它，其他网络不受影响
  • 网页版没有这个功能

选课和抢课

  • 登录验证码自动识别，识别不了再手动输入
  • 监控课程余量，有人退课时自动提交
  • 选课开放前排好要选的课，开放后马上提交
  • 登录失效后自动重新登录，可同时登录多个账号
  • 提交前检查实验班和教材选项，信息不全就不提交

网页版

不想安装客户端也可以用网页版，但要先装一个浏览器脚本。

学校的服务器不允许其他网站直接调用接口，浏览器会拦下这些请求。配套脚本通过脚本管理器转发请求，只对 bksxk.nwafu.edu.cn（选课）、ehall.nwafu.edu.cn 和 authserver.nwafu.edu.cn（教务和统一身份认证）这三个学校域名生效。
安装 篡改猴 (Tampermonkey) 或 脚本猫 (ScriptCat) 浏览器扩展。
安装 西农教务助手 · 网页版桥接 脚本，点开链接后在扩展里确认安装。
打开 网页版 并刷新，不再提示安装脚本就说明可以用了。
查课表、成绩等教务功能时，先在同一个浏览器里打开学校教务页面完成登录，再回到网页版点「连接当前浏览器会话」。网页版不会读取你的密码。

网页版只能在校园网内用，没有校外访问功能。浏览器通知需要授权；抢课监控在关闭标签页后会停止，放在后台的标签页也可能变慢。

常见问题

以前的「西农本科选课」去哪了？

就是这个应用。2.0 起改名为西农教务助手，加了课表、成绩等日常功能，选课和抢课都还在。

鸿蒙手机能用吗？

能安装 APK 的设备可以试 Android 版。纯血鸿蒙（HarmonyOS NEXT）暂时没有安装包。

西农教务助手 · 开源于 GitHub · 非学校官方应用

登录和教务数据只在你的设备和学校服务器之间传输。检查更新会访问 GitHub 和 mjy.js.org，不带任何学校账号信息。如果你在设置里配置了在线验证码识别服务，验证码图片会发给该服务。
